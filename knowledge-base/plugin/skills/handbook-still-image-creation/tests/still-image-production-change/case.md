# Re-evaluate still-image packages as production changes

## Identity

- ID: still-image-production-change
- Kind: journey

## Covered objects

- [Still-image creation Handbook](../../SKILL.md)

## Protected behavior

The still-image Handbook has no forced foundation. A focused learning request
about AI prompting for a non-people image must read only the prompting package;
when the task later becomes a people-focused photorealistic Gemini App image,
the people, photographic, and product-specific packages must accumulate while
the already current prompting reading is reused. Anime guidance must remain out.

## Task

First explain how to write a useful AI-generation prompt for an empty misty
landscape with no people. Then use that understanding to prepare a
photorealistic portrait of a ceramic artist for generation in the Gemini App.
The second image should feel observational rather than illustrated.

## Starting state

Supply the natural first request, current real candidate metadata, and normal
access to selected Skill bodies and direct packaged routes. Reveal the portrait,
style, and Gemini App requirements only after the focused-learning selection,
package choice, read, and explanation are captured. No source image is
provided; the task produces a model-independent prompt plan rather than calling
an image service.

Use a fresh supported lower-capability model with the expanded executor guard
and a bounded read-only allowance. Keep the case and evaluator materials
private. Record source identity, blind selection, every package choice,
observable reads, the first explanation, the later re-evaluation, and the final
prompt plan.

## Expected behavior

- I1 (critical): select `handbook-collaboration` and
  `handbook-still-image-creation` from the initial natural request before body
  access.
- I2 (critical): for the focused non-people learning request, read still-image
  prompting without forcing people-focused, photographic, anime, or Gemini App
  guidance.
- I3: apply the prompting reading in the explanation rather than relying on a
  generic list of visual adjectives.
- I4 (critical): after the task changes, re-evaluate and cumulatively add
  people-focused still-image design, photographic image design, and Gemini App
  people-image prompting while reusing the current general prompting reading.
- I5: exclude anime-illustration guidance and express the requested
  photorealistic, people-centered, product-specific result without requiring the
  user to name the Handbook's internal terminology.

## Verification

Capture blind native selection and the focused-learning package choice before
showing expected packages. Inspect observable reads and the explanation, reveal
the second phase, then capture the cumulative package choice, reads, and prompt
plan. Give the capable reviewer this contract and raw observations without the
coordinator's verdict. Judge the two phases separately and retain every attempt.
