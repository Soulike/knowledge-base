# Product-experience Handbook

This Handbook supplies required understanding for product-interface work. It
does not own the procedure or completion of the user's task. Apply its packaged
guidance as supplemental to instructions, requirements, Skills, and
project-specific decisions in the active working directory.

## Select required reading

Evaluate the foundation and every package condition from the current interface,
platform, artifact, task stage, and requested result. Read the complete
foundation whenever it applies and every matching package before the decisions
they inform; do not choose only the nearest match. A focused request to learn or
explain a package subject matches that package directly without forcing an
unrelated foundation.

## Foundation

When designing, implementing, reviewing, diagnosing, or evaluating an
interface, website, interaction flow, or product usability, or when learning
about cross-platform interface design as a whole, read all four files in full:

- [User-centered information hierarchy](../../knowledge/user-interface/user-centered-information-hierarchy.md)
- [Interaction clarity in user interfaces](../../knowledge/user-interface/interaction-clarity.md)
- [User goodwill in interface design](../../knowledge/user-interface/user-goodwill.md)
- [Resilient interface layouts](../../knowledge/user-interface/layout-resilience.md)

## Conditional required-reading packages

### Small touch-screen interfaces

When designing, implementing, reviewing, testing, diagnosing, evaluating, or
learning about an interface used on a small touch screen, read
[Mobile interface usability tradeoffs](../../knowledge/user-interface/mobile-interface-usability.md)
in full.

### Browser interfaces

When designing, implementing, reviewing, testing, diagnosing, evaluating, or
learning about a browser interface, read both files in full:

- [Content-resilient web layouts](../../knowledge/web-ui/content-resilient-layouts.md)
- [Baseline accessibility for web interfaces](../../knowledge/web-ui/web-accessibility-basics.md)

### Website entry points and navigation

When building, restructuring, reviewing, evaluating, or learning about a
website's overall entry points, home page, multi-page structure, or navigation,
read both files in full:

- [Home page purpose and entry points](../../knowledge/web-ui/home-page-purpose-and-entry-points.md)
- [Website navigation and orientation](../../knowledge/web-ui/site-navigation.md)
