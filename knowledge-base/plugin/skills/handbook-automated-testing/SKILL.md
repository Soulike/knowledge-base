# Automated testing Handbook

This Handbook supplies required understanding for automated-test work. It
selects reading rather than owning the user's testing task. Treat the guidance
as supplemental to instructions, requirements, Skills, and project-specific
decisions in the active working directory.

## Select the required reading

1. Resolve every link relative to this `SKILL.md`.
2. For work on concrete automated tests or their execution, read the complete
   foundation before making dependent test-design, execution, diagnosis, or
   review decisions. A direct learning or explanation request about one
   foundation subject may read its matching unit without loading the other one
   when no test artifact or execution work is present.
3. Evaluate every conditional package from the observable work and current
   materials. Read every matching package cumulatively. A direct learning or
   explanation request about a package's subject also matches that package
   without automatically loading the test-work foundation.
4. Reuse a reading unit that is already loaded, current, and available. Read it
   again when its content changed or after recovery or compaction when its
   necessary basis can no longer be established.
5. Re-evaluate this Handbook and all package conditions when the task phase,
   language, platform, artifact, production method, or available reading basis
   changes. Add newly required reading before dependent work.

This Handbook has no dependency on another Handbook. Continue the user's task
under the applicable Workflow or active-project process after loading and
applying the required understanding.

cost, or directly learning or explaining that subject, read
[Automated-test execution cost](../../knowledge/software-testing/test-execution-cost.md)
