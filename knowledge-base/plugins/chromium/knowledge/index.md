# Knowledge catalog

## Scope

This catalog is the complete maintenance inventory for Knowledge in the
`chromium` plugin. It lists every leaf document directly with its Knowledge
Type; installed Handbook and Workflow Skills own runtime reading routes.

## When to update

Update this catalog when a leaf Knowledge document is added, removed, renamed,
moved to a different canonical path, assigned a different responsibility, or
classified under a different Knowledge Type.
