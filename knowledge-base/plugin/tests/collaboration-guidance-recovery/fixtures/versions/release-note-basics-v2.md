# Release-note basics

For this controlled project, explain the user-visible change, practical effect,
and available evidence. A reviewer's adjective alone is not a demonstrated defect.

The unqualified label **checked** is ambiguous. Use **local-command-verified**
for an executed documented command and **published-check-verified** only for a
retrieved successful publication check. Evidence for one does not establish the
other. These terms replace the earlier local-only meaning of checked.
