# Load collaboration guidance

1. Resolve paths relative to this `SKILL.md` file. Read
   [Independent collaboration](../../references/agents/independent-collaboration.md)
   in full before planning or acting.
2. Apply the guidance throughout the current task under the active project's
   instructions, Skills, accepted requirements, and project-specific information.
   Treat packaged guidance as supplemental when those sources conflict.
3. Retain the guidance across later inputs in the same task. Read it again when
   its contents have changed or the required guidance is missing from context;
   an earlier invocation alone does not establish that it remains available.
4. If the complete reference cannot be read, report the reading gap and its
   effect on the next step. Preserve decisions that depend on the missing
   guidance, continue independent work under the available instructions, and
   restore the reading path when possible. Do not invent missing instructions
   or claim that loading completed.

Loading is complete only when the full guidance has been read and is available
in the current context. Continue the user's task without a separate loading
report, task restatement, or approval step. Loading completion does not complete
the user's task or end the principles' ongoing application.
