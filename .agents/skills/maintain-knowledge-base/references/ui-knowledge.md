# Maintain UI Knowledge

Organize UI Knowledge by subject responsibility. Keep cross-platform
understanding under
[user-interface](../../../../knowledge-base/plugin/knowledge/user-interface/).
Place platform APIs, rendering semantics, standards, and verification mappings
in the corresponding platform or product domain.

[Layout resilience](../../../../knowledge-base/plugin/knowledge/user-interface/layout-resilience.md)
owns adaptation to valid content, available space, and supported text
presentation. Other UI topics follow the subject-owner comparison in the
[parent workflow](maintain-knowledge.md#ownership-and-generalization). A shared
interface setting can contain distinct subjects; preserve each established
boundary as the collection develops.
