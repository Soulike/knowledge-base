# Video creation Handbook

This Handbook supplies required understanding for continuous-shot and
image-to-video work. It does not own the procedure or completion of the user's
task. Apply its packaged guidance as supplemental to instructions, requirements,
Skills, and project-specific decisions in the active working directory.

## Select required reading

This Handbook has no common foundation. Evaluate every package condition from
the current shot, subject, production method, visual medium, source materials,
and task stage. Read every matching package before the decisions it informs; do
not choose only the nearest match. A focused request to learn or explain a
package's subject matches that package directly without forcing an unrelated
package.

If no package matches, continue without
loading unrelated material; the available packages do not claim to cover every
kind of video work.

## Conditional required-reading packages

### Image-to-video prompting

When one or more source images condition video generation, when writing or
reviewing that prompt, when diagnosing a video generated from images, or when
learning about those activities, read
[Natural-language prompting for image-to-video generation](../../knowledge/generative-media/image-to-video-prompting.md)
in full.

### Continuous shots centered on people

When conceiving, producing, researching, reviewing, diagnosing, or learning
about one continuous shot centered on one or more people, regardless of whether
it is filmed, animated, or generated, read
[People-focused continuous-shot design](../../knowledge/generative-media/people-focused-continuous-shot-design.md)
in full.

### Live-action or photorealistic continuous shots centered on people

When conceiving, producing, researching, reviewing, diagnosing, or learning
about a live-action or photorealistic continuous shot centered on people, read
both files in full:

- [People-focused continuous-shot design](../../knowledge/generative-media/people-focused-continuous-shot-design.md)
- [People-focused photographic-video design](../../knowledge/generative-media/people-focused-photographic-video-design.md)

### Anime- or manga-influenced continuous shots centered on people

When conceiving, producing, researching, reviewing, diagnosing, or learning
about an anime- or manga-influenced continuous shot centered on people, read
both files in full:

- [People-focused continuous-shot design](../../knowledge/generative-media/people-focused-continuous-shot-design.md)
- [People-focused anime-animation design](../../knowledge/generative-media/people-focused-anime-animation-design.md)
