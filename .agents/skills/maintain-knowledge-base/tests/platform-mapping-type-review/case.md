## Protected behavior

Correct classification of mixed content must not substitute for ownership
assessment. A proposed type change must distinguish the durable argument
principle from independently needed PowerShell/.NET interface behavior and keep
both usable. Allow different new leaf names and prose while preserving the
independent subjects, necessary conditions, and direct reading routes.
