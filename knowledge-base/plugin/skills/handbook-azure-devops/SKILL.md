# Azure DevOps handbook

This platform Handbook routes the curated Azure DevOps guidance currently
available in this plugin. Its coverage is intentionally non-exhaustive. It owns
required-reading selection, not the procedure or completion of the user's task.
Resolve every packaged link relative to this `SKILL.md`, and apply selected
Knowledge as supplemental guidance under the instructions, requirements,
Skills, and project-specific decisions in the active working directory.

## Read the required material

Evaluate every condition below. Every match is required and cumulative with
any other matching package added to this Handbook later.

- When preparing or reviewing diagrams in an Azure DevOps pull-request
  description, or when the user asks to learn or explain how to publish and
  verify diagrams there, read [Diagrams in Azure DevOps pull request
  descriptions](../../knowledge/azure-devops/pull-request-diagrams.md).

If no current package matches, the Handbook's reading selection is validly
complete with no package to read. Continue the task without applying unrelated
narrow material, inventing guidance, or implying that this Handbook documents
all of Azure DevOps. Do not copy or infer rules in place of reading the linked
canonical material.

Re-evaluate this Handbook and every package condition when the task stage,
platform, artifact, production method, or available reading basis changes.
Reuse a reading unit that is still current and available; reread it when it
changed or its necessary context is no longer available. If required material
cannot be read, report the gap and its effect on the task instead of inventing
or silently omitting the guidance.
