# Knowledge-base plugin

The plugin combines independently retrievable understanding with Agent
workflows that select and apply it.

## Language

**Knowledge**:
Understanding with a concrete reading reason arising from the task or subject,
independent of any consuming workflow.

**Skill**:
An Agent workflow that owns the decisions, steps, and completion criteria for a
user task.

**Skill reference**:
Supporting material selected by a step in an executing Skill. Sharing it among
Skills does not create an independent Knowledge reading responsibility.
