## Task

Explain why a skipped GitHub Actions job can appear successful while required
validation is absent, and how a required final status should avoid accepting
that result. Distinguish a successfully established non-applicable path from a
failure, cancellation, unexpected skip, or missing result. This is a focused
explanation; do not create, change, review, or diagnose a concrete workflow.
