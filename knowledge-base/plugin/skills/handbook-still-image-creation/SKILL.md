# Still-image creation Handbook

This Handbook supplies required understanding for still-image work. It does not
own the procedure or completion of the user's task. Apply its packaged guidance
as supplemental to instructions, requirements, Skills, and project-specific
decisions in the active working directory.

## Select required reading

This Handbook has no common foundation. Evaluate every package condition from
the current image, subject, production method, visual medium, generation
surface, and task stage. Read every matching package before the decisions it
informs; do not choose only the nearest match. A focused request to learn or
explain a package's subject matches that package directly without forcing an
unrelated package.

If no package matches, continue
without loading unrelated material; the available packages do not claim to
cover every kind of still-image work.

## Conditional required-reading packages

### AI still-image prompting

When using AI to generate a still image, writing or reviewing its prompt,
diagnosing a generated result, or learning about those activities, read
[Natural-language prompting for generated still images](../../knowledge/generative-media/still-image-prompting.md)
in full.

### Images centered on people

When conceiving, creating, researching, reviewing, diagnosing, or learning
about a still image in which one or more people are the visual focus, regardless
of whether it is photographed, illustrated, or generated, read
[People-focused still-image design](../../knowledge/generative-media/people-focused-still-image-design.md)
in full.

### Photographic or photorealistic images centered on people

When conceiving, creating, researching, reviewing, diagnosing, or learning
about a photographic or photorealistic still image centered on people, read
both files in full:

- [People-focused still-image design](../../knowledge/generative-media/people-focused-still-image-design.md)
- [People-focused photographic-image design](../../knowledge/generative-media/people-focused-photographic-image-design.md)

### Anime- or manga-influenced images centered on people

When conceiving, creating, researching, reviewing, diagnosing, or learning
about an anime- or manga-influenced still illustration centered on people, read
both files in full:

- [People-focused still-image design](../../knowledge/generative-media/people-focused-still-image-design.md)
- [People-focused anime illustration design](../../knowledge/generative-media/people-focused-anime-illustration-design.md)

### Gemini App images centered on people

When using the Gemini App to generate, edit, review, or diagnose a still image
centered on people, or learning about that product-specific work, read all three
files in full:

- [People-focused still-image design](../../knowledge/generative-media/people-focused-still-image-design.md)
- [Natural-language prompting for generated still images](../../knowledge/generative-media/still-image-prompting.md)
- [Gemini App people-image prompting](../../knowledge/generative-media/gemini-app-people-image-prompting.md)
